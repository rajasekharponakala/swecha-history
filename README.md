# Swecha History

A historical timeline of **Swecha** — a technology-for-society organisation committed to promoting Free and Open Source Software (FOSS).

Swecha (Telugu: *Swecha* / *స్వేచ్ఛ*) was founded in 2005 as an organisation to support the Swecha project: a Telugu localisation of GNU/Linux and Free Software. It grew into a vibrant community of software users, students, academicians and developers, and is a regional movement within the [Free Software Movement of India (FSMI)](https://en.wikipedia.org/wiki/Free_Software_Movement_of_India).

This repository collects **publicly available information** about Swecha's history, milestones, projects and programmes, and presents them as a structured, source-backed timeline.
